# Attribution

This project is a derivative work built on the **open-source federal contracting
skills framework** created by **James Jenrette** — [1102tools.com](https://1102tools.com).

The upstream framework supplied the SOW/PWS decision-tree logic, the derivation
approach, and — most importantly — the design principle that staffing, CLIN, and
justification data must stay outside the requirement document body. That firewall
is preserved intact in this implementation.

## What this project adds

- A browser-based guided wizard over the decision-tree logic
- Five acquisition domains: IT, non-IT services, construction, A/E, R&D
- RFO / EO 14402 awareness with regime-resolved citations (codified FAR vs. model deviation text)
- Dated, source-linked authority register
- EO 14402 fixed-price gate with FAR 16.104 justification as a separate workpaper
- Word / PDF export and local draft save-load
